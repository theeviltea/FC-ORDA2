# ORDA — фан-приложение ФК «Ордабасы»

Expo SDK 57 · React Native 0.86 · TypeScript · expo-router. Одна кодовая база на iOS, Android и web
(web-сборка — кликабельный прототип по ссылке: https://theeviltea.github.io/FC-ORDA2/).

## Запуск

```bash
npm install
npm run web        # прототип в браузере
npm run ios        # / npm run android — через Expo Go или dev build
npm run typecheck
npm run lint
```

## Структура

```
design/tokens.json        токены из ORDA Design System (источник правды)
scripts/build-tokens.mjs  tokens.json → src/theme/tokens.ts  (npm run tokens)
src/theme/                цвета, градиенты, радиусы, тени, шрифты SO Sporty + Roboto Condensed
src/icons/icons.ts        иконки Hugeicons из компонента Icon дизайн-канваса
src/components/           компоненты 1:1 с дизайн-системой (TabBar, AppHeader, GuestHeader, NavBar, OfferBanner…)
src/data/                 моки (профиль, лента главной) и карта картинок
src/features/             экраны, собранные из компонентов
src/app/                  роуты expo-router: файл = роут
assets/                   шрифт SO Sporty и картинки, выгруженные с канваса
```

## Что готово

- Таб-бар: Главная · Медиа · Матчи · Магазин · Фан-зона (плавающая карточка, как в дизайне)
- Главная `/` — шапка с профилем и баллами, истории, билет, ближайший матч с обратным отсчётом,
  «Для вас», магазин, видео, игрок матча, команда, турнирная таблица, новости, партнёры
- Авторизация (прототип): по умолчанию вы вошли; «Выйти из аккаунта» в профиле → гостевая зона (шапка с «Войти», баннер «Стань частью ORDA»). Вход `/login` (любой полный номер + любой пароль), регистрация `/register` → код из SMS (любые 6 цифр) → главная с новым именем и фото, восстановление `/forgot` → код → новый пароль → вход
- Профиль `/profile` — открывается по аватару в шапке
- Медиа, Матчи (расписание · результаты · таблица), Магазин (витрина · мои заказы), Фан-зона
- Шапка экрана (AppHeader / GuestHeader / NavBar) всегда закреплена сверху — проп `header` у `Screen`
- Карточка товара `/product/[id]` (галерея, размер/цвет/кол-во, промокод ORDA15, похожие, панель «Купить»), история покупок `/orders`
- Покупка билетов `/tickets` (схема стадиона, 4 трибуны, количество до 6, «Оплатить») и состав команды `/lineup` (тренер, расстановка 4-3-3, старт, запасные)
- Новости `/news` (темы, главная, лента) и статья `/news/[id]` (текст с фото, лайки, «Показать больше», поле комментария — комментарий добавляется в список)
- Команда `/team` (сезон, переходы по линиям, игроки, тренеры и персонал) и профиль игрока `/player/[num]` (полный профиль у №10, у остальных — карточка и основные данные)
- Фото: список `/photos`, альбом `/photos/[id]`, просмотр `/photos/viewer`; Видео: ORDA TV `/videos`, плеер `/video/[id]`, полный экран `/video/fullscreen`, моменты `/moments`
- Уведомления `/inbox` (фильтры, «Прочитать все», Сегодня/Ранее) и их настройки `/notification-settings`; настройки `/settings`; мои достижения `/achievements`
- Мои билеты `/my-tickets` (активный билет, прошедшие) и боттомшит с QR-кодом билета `TicketQRSheet` (обновляется каждые 30 с, листание между билетами) — открывается из билетов, профиля и главной
- Личные данные `/personal` (редактирование с проверкой полей, имя сразу видно в профиле), центр поддержки `/support` (контакты, частые вопросы, форма обращения), язык `/language` (выбор сохраняется и показывается в настройках)
- Безопасность `/security` → смена пароля: код из SMS `/password/code` (компонент `OtpInput`, таймер повторной отправки, ошибка с попытками; в демо неверный код — 000000) → новый пароль `/password/new` (шкала надёжности, проверка совпадения, показать/скрыть)
- Викторины `/quizzes` (Фан-зона → Викторины; фильтр, 4 состояния карточки) → вопрос `/quiz/[id]` (выбор, ответ, верно/не совсем, прогресс и баллы; прогресс сохраняется) → итог `/quiz/result`
- Конкурсы `/contests` (Фан-зона → Конкурсы; 4 состояния) → конкурс `/contest/[id]` (отсчёт до конца приёма, приз, шаги) → заявка `/contest/apply` (фото из галереи через expo-image-picker, согласие) → «Заявка отправлена» `/contest/sent`; «Моя заявка» и победители `/contest/winners`
- Для вас `/for-you` (фильтр Все / Скидки / Эксклюзив / Бонусы) → предложение `/offer/[id]`: промокод с копированием (expo-clipboard) и переходом к товару с подставленным кодом, вопрос в эфир, серия матчей, напоминание
- Внутренние экраны пока заглушки «Скоро здесь» (`/soon?title=…`)

## Правила

- Цвета — только из токенов (`colors.*` или имя токена в `color` у `Text`/`Icon`).
- Новые экраны собираем из `src/components`. Нужного компонента нет — сначала дизайн-система, потом сюда.
- Заголовки — SO Sporty (`<Text display>`), остальной текст — Roboto Condensed.
- Навбар второго уровня — `NavBar`: «Назад» слева, заголовок по центру, одна иконка справа.

## Деплой превью

Пуш в `main` → GitHub Actions собирает web (`npm run export:web`) и кладёт `dist` в ветку `gh-pages`.
GitHub Pages раздаёт её по адресу https://theeviltea.github.io/FC-ORDA2/.

Превью-артефакт «ORDA App Preview» (как у 919): `npm run build:artifact` собирает один HTML со встроенными
JS, картинками и шрифтами в `preview/orda-preview.html`, его публикуем в артефакт.

Демо: промокод `ORDA15` — скидка 15%, любой другой — ошибка. Шарф — товар без фото.
